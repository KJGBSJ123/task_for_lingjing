学习残差块的构建
1.ResNet：最新的卷积神经网络，用于解决训练轮数增加导致准确度不升反降的问题。
                  方法：只算残差，然后直接加输入值
2.残差块的组成：
                 输入->卷积层1->规范化层1->Relu激活层->卷积层2->规范化层2->+输入->Relu激活层
                 卷积层：用卷积核扫描，并获取信息
                 激活层：Relu(输入大于0就为本身，小于就为0)，便于模拟
                 规范化层：用于数据的归一化(可能出现极端数据，如10000000000，-1，0.2，1之类的)，一般是求线性回归。
